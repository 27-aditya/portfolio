## Sentinel ANPR
- tech: Python, YOLO, Master/Slave Architecture, Graffana, Prometheus, Auto-scaling Workers, Distributed Systems, Redis
- href: https://github.com/sentinel-ANPR

A complete ANPR system developed for Kozhikode DTPC. Distributed system with master slave architecture whic is able to process multiple locations for data like vehicle number, logo, color and traffics violations. Maintains a suspect list for vehicles when spotted will trigger an alert on the admin panel, uses redis for fast lookup in constant time. Graffana and prometheus for monitoring the edge devices and stats on the vehicles.
